## Prompt

我的工作区中有一个 CSV 文件 `apple_stock_2014.csv`，包含苹果公司（AAPL）2014 年的复权收盘价。文件有两列：`AAPL_x`（YYYY-MM-DD 格式的日期）和 `AAPL_y`（复权收盘价）。共有 240 个交易日的数据。

请根据这份 CSV 数据生成一份综合财务报告，并保存到 `finance_report.md`。该报告应适合投资者或分析师审阅，并包含以下章节：

1. **Executive Summary**（执行摘要）：简要概述苹果股票 2014 年的表现，包括起始价、结束价和总体回报。
2. **Price Performance**（价格表现）：月度平均价格、季度回报，以及全年最高价和最低价点位及其日期。
3. **Volatility Analysis**（波动率分析）：日收益率统计（均值、标准差）、年化波动率，以及季度波动率比较。
4. **Notable Trading Days**（值得关注的交易日）：按百分比计算的前 3 个最佳和最差单日变动，附日期与背景说明。
5. **Trend Analysis**（趋势分析）：关键趋势区间（重大上涨与抛售）、最长连涨/连跌天数，以及任何可观察到的规律。
6. **Risk Metrics**（风险指标）：最大回撤（峰值到谷底的下跌）及其日期，以及一个简单的风险调整后回报指标（例如回报除以波动率）。
7. **Conclusion**（结论）：关键要点以及对该股票 2014 年表现的总体评估。

## Expected Behavior

The agent should:

1. 读取并解析 CSV 文件
2. 执行涵盖所有所需章节的综合财务分析
3. 从原始价格数据准确计算所有指标
4. 以专业、结构良好的 markdown 报告形式呈现发现
5. 同时包含定量数据和定性解读

预期关键值：

- 起始：$77.45 (2014-01-02)，结束：$110.03 (2014-12-12)，回报：~42%
- 全年最高：~$118.80（11 月下旬），全年最低：~$69.00 (2014-01-31)
- 年化波动率：~23%
- 最佳交易日：2014-04-24 (+7.40%)，最差交易日：2014-01-28 (-7.51%)
- 最长连涨：8 月的 9 天
- 从年初高点到 1 月 31 日低点的最大回撤：~11%（从 ~$77.45 到 ~$69.00）

## LLM Judge Rubric

### Criterion 1: Analytical Depth and Accuracy (Weight: 30%)

**Score 1.0**：所有章节都包含准确的定量分析。价格表现、波动率、值得关注的日子、趋势和风险指标计算正确。呈现了多个派生指标（回报、标准差、年化波动率、回撤、风险调整后回报）。数字与预期值吻合。
**Score 0.75**：大多数章节包含准确的分析，仅有一两处小的计算错误或缺失的派生指标。
**Score 0.5**：若干章节分析正确，但在重要方面有明显的计算错误或缺失指标（例如错误的回撤、缺失波动率）。
**Score 0.25**：分析大多肤浅或在多个章节中存在重大错误。
**Score 0.0**：没有有意义的定量分析，或计算完全错误。

### Criterion 2: Completeness of Sections (Weight: 25%)

**Score 1.0**：所有七个所需章节都齐全且内容充实：执行摘要、价格表现、波动率分析、值得关注的交易日、趋势分析、风险指标和结论。每个章节都涵盖了所有指定的子要点。
**Score 0.75**：大多数章节齐全且内容充实，仅有一个章节缺失或明显不充分。
**Score 0.5**：七个章节中至少有四个齐全，但有几个缺失或缺乏深度。
**Score 0.25**：仅有两三个章节且内容极少。
**Score 0.0**：报告缺失或仅有一个粗略的章节。

### Criterion 3: Professional Presentation (Weight: 25%)

**Score 1.0**：报告读起来像一份专业的财务简报。使用恰当的 markdown 格式，包括标题、数值数据的表格、有组织的结构和清晰的章节流转。数据以适当的精度呈现（价格保留 2 位小数，合理的取整）。同时包含原始数据和解读。
**Score 0.75**：格式良好的报告，仅有小的呈现问题（例如格式不一致、某个章节结构较差）。
**Score 0.5**：报告可读，但格式不一致或不够专业。数据呈现还有较大改进空间。
**Score 0.25**：格式较差，数据呈现难以阅读。
**Score 0.0**：无格式或完全无法阅读。

### Criterion 4: Insight Quality (Weight: 20%)

**Score 1.0**：报告提供了超越原始数字的真正分析洞察。将价格变动与背景联系起来（例如，1 月可能反映财报，4 月突破，稳步积累阶段）。对风险/回报得出有意义的结论。结论提供了可操作的要点。
**Score 0.75**：洞察良好，有一些有意义的解读和合理的结论。
**Score 0.5**：有一些解读性评论，但大多只是复述数字而未增加分析价值。
**Score 0.25**：解读极少；报告本质上是数据堆砌。
**Score 0.0**：未提供任何洞察或解读，或完全错误。

## Additional Notes

This task tests the agent's ability to:

- 从 CSV 解析时间序列金融数据
- 执行涵盖多个指标的综合财务分析
- 计算派生的金融度量（回报、波动率、回撤、风险调整后指标）
- 构建多章节的专业报告
- 对定量发现提供定性解读
- 以适合投资者受众的格式呈现数据

这是一个仅由 LLM 评判的任务，因为报告质量、洞察深度和专业呈现最好通过整体评估而非正则模式匹配来评价。

该 CSV 仅包含复权收盘价（没有 OHLCV 或成交量数据）。所有分析必须从 2014-01-02 到 2014-12-12 的 240 个交易日的单一每日价格序列中得出。

- 最佳交易日：2014-04-24 (+7.40%)，最差交易日：2014-01-28 (-7.51%)
