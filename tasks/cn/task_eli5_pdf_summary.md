## Prompt

阅读工作区中的 `GPT4.pdf` 文件。这是一篇关于 GPT-4 的技术论文。撰写一份"像对 5 岁小孩解释"（ELI5）风格的论文摘要，并将其保存到 `eli5_summary.txt`。

摘要应当：
- 让一个没有任何技术背景的小孩也能听懂
- 使用简单的词语、短句子和日常生活中的类比
- 涵盖论文的主要观点（GPT-4 是什么、它能做什么、为什么它重要）
- 大约 200-400 词

## Expected Behavior

Agent 应当：

1. 读取并解析 PDF 文件 `GPT4.pdf`（OpenAI 的 GPT-4 技术报告）
2. 识别论文的关键主题和发现，包括：
   - GPT-4 是一个大型多模态模型，可接受文本和图像输入并产生文本输出
   - 它在各种专业和学术基准测试上展现出人类水平的表现
   - 它使用大规模、可预测的训练流程进行训练
   - 进行了安全与对齐方面的工作（RLHF、红队测试等）
   - 仍然存在局限性（幻觉、推理错误等）
3. 将这些技术概念用类比和日常对比转化为简单、适合儿童理解的语言
4. 将 ELI5 摘要写入 `eli5_summary.txt`

摘要应避免使用诸如 "multimodal"、"transformer"、"RLHF"、"benchmark"、"parameters" 等行话。相反，应使用小孩能理解的类比（例如，"像一个非常聪明的小助手，会读字又会看图"）。

## Grading Criteria

- [ ] Agent 成功读取/解析了 PDF 文件
- [ ] 输出文件 `eli5_summary.txt` 已创建
- [ ] 摘要用简单的话解释了 GPT-4 是什么
- [ ] 摘要涵盖了 GPT-4 能做什么（理解文字、图像、回答问题、考试）
- [ ] 摘要提及人们为让它更安全/更友善所做的工作
- [ ] 摘要承认其局限性（它仍可能犯错）
- [ ] 语言确实简单——没有技术行话
- [ ] 使用了小孩能理解的类比或对比
- [ ] 摘要篇幅适中（大约 200-400 词）
- [ ] 行文清晰、连贯、引人入胜

## LLM Judge Rubric

### Criterion 1: Simplicity and Accessibility (Weight: 35%)

**Score 1.0**: 摘要确实能让一个小孩听懂。句子简短简单。完全没有技术行话。使用具体、日常的语言和贴切的类比（例如把模型比作乐于助人的朋友、非常优秀的学生，或会学习的玩具）。一个 5 岁孩子能够跟上。
**Score 0.75**: 摘要大体简单，只有一两个略微高级、小孩可能无法完全理解的词或概念，但整体易懂。类比运用得当。
**Score 0.5**: 摘要尝试做到简单，但包含若干会让小孩困惑的技术术语或抽象概念。类比薄弱或缺失。
**Score 0.25**: 摘要读起来更像是简化版的成人摘要，而非 ELI5。包含明显的行话或假设了背景知识。
**Score 0.0**: 摘要完全技术化，通篇使用行话，或没有为低龄读者做任何简化努力。

### Criterion 2: Accuracy and Coverage (Weight: 30%)

**Score 1.0**: 摘要准确抓住了 GPT-4 论文的核心观点：GPT-4 是什么（一个大型 AI 模型）、它能做什么（理解文字和图像、在考试/基准测试中表现出色）、为其安全付出了努力、以及它仍有局限。没有事实错误。
**Score 0.75**: 摘要涵盖了大多数关键观点，仅有细微遗漏（例如漏掉图像理解方面或安全工作）。没有重大事实错误。
**Score 0.5**: 摘要涵盖了一些关键观点，但遗漏了论文的重要方面，或包含细微的不准确之处。
**Score 0.25**: 摘要只是浅显地触及论文内容，或包含明显的事实错误。
**Score 0.0**: 摘要偏离主题、事实错误，或缺失。

### Criterion 3: Engagement and Tone (Weight: 20%)

**Score 1.0**: 摘要温暖、友好、引人入胜。感觉像是有人真的在跟一个孩子说话——使用对话式语气、有趣的对比，以及一种好奇与惊奇的感觉。读者会乐于阅读。
**Score 0.75**: 摘要总体语气友好，有一些吸引人的元素，但可以更生动或更具对话感。
**Score 0.5**: 摘要功能性尚可但枯燥。它简化了内容，但读起来像平淡的内容概要，而非 ELI5 式的讲解。
**Score 0.25**: 摘要生硬、过于正式或乏味。没有努力让它对低龄读者有吸引力。
**Score 0.0**: 语气完全不适合儿童读者，或内容缺失。

### Criterion 4: Task Completion (Weight: 15%)

**Score 1.0**: Agent 成功读取了 PDF，产出了保存到 `eli5_summary.txt` 的摘要，且摘要在目标篇幅范围内（200-400 词）。
**Score 0.75**: Agent 完成了任务，仅有细微问题（例如文件名略有不同，或词数略微超出范围但仍合理）。
**Score 0.5**: Agent 完成了任务，但存在明显问题（例如摘要过短或过长，或 Agent 在读取 PDF 时遇到很大困难）。
**Score 0.25**: Agent 部分完成了任务——文件已创建但内容严重不足，或 PDF 未被正确读取。
**Score 0.0**: 未创建输出文件，或 Agent 完全未能读取 PDF。

## Additional Notes

本任务检验 Agent 的以下能力：

- 解析 PDF 文档（GPT-4 技术报告，一篇篇幅可观的学术论文）
- 将复杂的技术内容提炼为极其简单的语言
- 为抽象概念创作富有创意、适合儿童的类比
- 在准确性与可理解性之间取得平衡

GPT-4 技术报告是 OpenAI 发布的一篇真实论文。它涵盖了模型的能力、训练流程、安全缓解措施和局限性。挑战不仅在于摘要本身，更在于彻底的简化——Agent 必须剥离所有技术复杂性，同时保留核心信息。
